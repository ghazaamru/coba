# Product Context

## Platform
web

## Target Audience & Core Purpose
- **Audience**: Individuals wanting a fast, private, distraction-free personal expense and income tracker.
- **Core Purpose**: Provide immediate, zero-latency transaction logging and balance tracking with 100% offline-first local persistence (IndexedDB / LocalStorage) and instant JSON backup/portability.

## Register & Brand Personality
- **Register**: Product (utility app, dense transactional ledger).
- **Tone**: Technical Precision — minimalist, dense, monospace numerical alignments, dark theme, low-noise aesthetic inspired by high-reliability developer & financial terminal tools.
- **Anti-References**: Cluttered dashboards with promotional banners, slow cloud-sync spinners, gratuitous AI chatbots, low-contrast washed-out text, bouncy unnecessary micro-animations.

## Key Workflows & Features
1. **Quick Transaction Logging**: Fast entry modal / bottom-sheet for income and expense postings with category tags, notes, and dates.
2. **Real-time Ledger Breakdown**: Monthly overview with net position, inflow/outflow metrics, and categorical expense distributions.
3. **Stream & Search**: Chronological date-grouped activity stream with multi-criteria filtering (query, type, category).
4. **Data Portability & Offline**: Standalone local storage, offline status indicator, PWA installation, and complete JSON export/import.

## Accessibility & Performance Principles
- High contrast ratios on dark backgrounds (WCAG AA compliance).
- Keyboard accessible inputs, explicit focus rings, and proper ARIA labeling for interactive triggers.
- Sub-millisecond local interactions with zero network round-trip dependencies for core functionality.
